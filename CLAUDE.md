# Portfolio tracker

SvelteKit app for tracking investment holdings across accounts. SQLite via Drizzle, UI built with shadcn-svelte + Tailwind v4, tables with TanStack Table.

## Commands

Uses bun (`bun.lock`).

- `bun run dev` — dev server on :5173
- `bun run check` — svelte-check (types)
- `bun run lint` — prettier check + eslint
- `bun run format` — prettier write
- `bun run db:generate` / `db:migrate` — create / apply Drizzle migrations after editing `schema.ts`
- `bun run db:reset` — delete `local.db`, migrate, and reseed

Run `check` and `lint` after changes.

## Layout

- `src/routes/` — pages: `dashboard`, `portfolio`, `accounts`, `accounts/[id]` (+ `upload` for CSV import), `securities`, `securities/[id]`
- `src/lib/server/db/schema.ts` — tables: account, security, holding, price_snapshot, tag, account_tag, price_basis, plus sector/region/security_type lookups
- `src/lib/server/db/queries/` — shared queries. `holdingRows()` is the "super query" joining each holding to its account, security attributes, and latest price; reuse it rather than rewriting the joins
- `src/lib/server/fmp.ts` — Financial Modeling Prep client (`FMP_API_KEY`) used to sync prices and security metadata
- `src/lib/components/ui/` — generated by shadcn-svelte; add components with the CLI rather than hand-writing them
- `src/lib/components/data-table/` — `DataTable` (generic TanStack wrapper), `SecurityDetailTable` (adds symbol/name/type/sector/region columns), `TableSearch`, column filter/sort headers

## Conventions

- Svelte 5 runes only (`$state`, `$derived`, `$effect`, `$props`, snippets); no legacy `export let` or stores.
- Table search, column filters, and sort live in the URL via `nuqs-svelte` (`?search=`, `?sort=`, `?<columnId>=`). `TableSearch` reads the same `search` param as `DataTable`, so it can go anywhere on the page. Put it in `PageHeader`'s `toolbar` snippet so it sticks with the header.
- Internal links go through `resolve()` from `$app/paths` (enforced by eslint).
- Money is formatted with `formatMoney` from `$lib/format`.

## Naming

Every variable, parameter, and callback argument gets a descriptive name. No single-letter or cryptic abbreviated names, including in short arrow functions:

```ts
// No
holdings.map((r) => r.id);
rows.reduce((sum, r) => sum + r.totalValue, 0);

// Yes
holdings.map((holding) => holding.id);
holdings.reduce((sum, holding) => sum + holding.totalValue, 0);
```

Name things after what they are in the domain (`holding`, `account`, `security`, `filter`, `event`), not their shape (`r`, `x`, `item`, `obj`). When editing a file, rename any short names in the code you touch.
